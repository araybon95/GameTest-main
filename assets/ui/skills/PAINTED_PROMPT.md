# Painted skill icons

Built-in image-generation tool; final atlas: painted_skills.png. Each ability has a separate .tres atlas resource; a per-ability .png override takes precedence, so individual artwork can be replaced later without regenerating the sheet. Existing SVGs remain available as editable fallbacks.

Production raster skill icon sheet for a grimdark 2D RPG. EXACTLY 25 icons in a perfect 5 columns by 5 rows grid on square canvas, each cell equal with generous transparent padding so each icon fits entirely in its own cell. Transparent background, NO borders, NO text or numbers, NO UI. Heavy black ink contours, angular flat shading, dark desaturated bronze/iron/blood, tiny bright accents, hand-painted distressed surfaces, bold simple recognizable silhouettes readable at 64px. Each icon is centered. Row 1 Warden, left to right: iron sword slash, round iron shield, shield smashing a cracked helm, sword overhead heavy strike, chained gauntlet drawing enemy attention. Row 2 Ranger: arrow with speed trails, crossed volley arrows, long armor-piercing arrow, green eye over marked target, leather boot evading an arrow. Row 3 Occultist: violet curse sigil, bloody draining hand, violet fire eruption from skull, ritual barrier circle, dark sacrificial spell book. Row 4 Healer: gold healing hands, illuminated prayer parchment, holy radiant hammer, sunburst against skull, golden protective ward. Row 5 Penitent Crusader: barbed axe, spiked iron shoulder shield, bleeding heart wrapped in thorns, barbed armored shoulder charging forward, heavy serrated axe and blood-red judgment halo. SAME consistent painting style across all 25, no tiny fine inscriptions, no drop shadows outside each cell.
