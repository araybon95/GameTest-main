# Combat and camp scenery

Eight original backgrounds generated with the built-in image-generation tool. Each PNG is independently replaceable. The existing scenery files are retained. The supplied dungeon wall was used as an ink/shape-language reference; the existing Crusader sheet was used as a character-shading reference. Exact generation prompts are in PROMPTS.json.

Combat PNGs are wide side-view stages displayed within the 1920×600 battlefield. Camps use independent 16:9 compositions with a centered fire and a clear ground plane for seated heroes. Corridor layers remain in the hallway traversal view. New scene lighting is cosmetic and cannot affect damage or progression.

The character-motion recording was reviewed by extracting frames from the user's 21-second MP4. It shows combat rather than hallway walking: held attack poses, quick contact, pronounced recoil and a camera push with nonparticipants dimmed. This pass strengthens the contact camera push while leaving the lower HUD readable.
