# Enemy variants

## Hooded Ash Raider

`ash_raider_hooded.png` is original AI-assisted artwork generated on 14 October
2026 using the project's existing Ash Raider image as a style reference, then
edited to separate the attack cells. It retains the project's ink outlines and
distressed painted leather/steel palette.

The complete transparent 12-pose sheet is retained without raster cropping.
Godot samples measured regions in `scripts/enemy_variants.gd`; frame margins
register the body and ground anchors. See `docs/enemy_variants.md` for frame
order, playback, and validation.
