# Dedicated battlefield ground

[Watch the in-game GIF](battlefield-ground.gif) · [Download the video](battlefield-ground.mp4)

Normal Heavy Strike with the existing background camera zoom. The dedicated painted floor stays still and every combatant shares its surface. This change is integrated into the game, rather than an isolated design mockup.

The floor reuses each environment's existing painted floor band, with a 24-pixel blend above the foot line. Bandit, keep, beast and medical combat rooms all have their own matching surface. No new artwork or physical collision system is required.
