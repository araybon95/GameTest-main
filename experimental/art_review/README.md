# ChatGPT artwork review downloads

Prepared from artwork snapshot `80d4012`. This is a review kit; the artwork audit has not yet been completed.

Download and extract these packs:

1. [Current frames and comparisons](01-current-frames.zip) — 160 transparent frame exports, grouped sheets and exact source mappings.
2. [All source overviews](02-all-source-overviews.zip) — 118 labeled pages, original paths, hashes and duplicate aliases.
3. [Animation review](03-animation-review.zip) — 28 storyboards and 332 sampled motion frames, including impact-focused execution samples.

Paste the [review prompt](REVIEW-PROMPT.md) into ChatGPT, then attach the extracted JPG/PNG images in small batches. Start with Witch Hunter Judgment and execution. Uploading a ZIP alone does not guarantee its images are visually inspected.

[Detailed instructions](START-HERE.md) · [Batch request](BATCH-REQUEST.md) · [Findings template](FINDINGS-TEMPLATE.csv) · [Coverage](COVERAGE.json) · [ZIP checksums](SHA256SUMS.txt)

[Download all full-resolution original project artwork](https://github.com/araybon95/GameTest-main/archive/80d401207b24c3e2bae3d096e1f3fedda0e79a3f.zip). The packs cover all 505 tracked image/media sources through overviews, exact duplicate aliases, OpenRaster layers or motion storyboards. Motion sampling is not exhaustive. Source-index links retrieve individual originals when a detail needs closer inspection.

The prompt checks anatomy, matching armor, weapon handles, hammer alignment, grip, contact, projectile orientation, dropped weapons, foot placement and frame continuity. It distinguishes source-art defects from crop/registration, scale, timing and draw-order problems. Historical designs and selectable outfits are labeled separately from current defaults.
